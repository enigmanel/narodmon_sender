# Изменения

## 0.1.3

### Возможности

- Новые отчёты сенсоров отбираются по `last_reported` вместо `last_updated`. Повторный отчёт с тем же значением теперь учитывается. Сравнение сохраняет доли секунды.
- Для каждого сенсора можно независимо включить режим optimistic в настройках интеграции. В этом режиме текущее валидное показание отправляется каждый раз, а в пакет передаётся время отправки. По умолчанию режим выключен.
- Настройка optimistic доступна при добавлении устройства и при редактировании. Проверка числовых значений действует в обоих режимах отправки.
- Обновлены русские и английские подписи настроек и инструкция в README.

### Исправления

- При выгрузке интеграции выгружается платформа `sensor`. Задача отправки отменяется и данные удаляются только после успешной выгрузки платформы.
- TCP-отправка ограничена общим тайм-аутом 20 секунд. Соединение закрывается при ошибке и отмене; ожидание закрытия ограничено 5 секундами.

### Проверка

- Все 21 автоматический тест проходят.
- Тестовая версия `0.1.3b1` проверена пользователем на своей установке Home Assistant; проблем не обнаружено.
